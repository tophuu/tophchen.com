# CLAUDE.md

Personal website (tophchen.com), built with Next.js 16 (App Router), React 19, Tailwind CSS 4, TypeScript.

## Git

**Never run `git commit` or `git push`.** The user commits and pushes manually. Leave changes staged/unstaged in the working tree and let them review before committing.

## Commands

- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run lint` — eslint

## Notes

- See `AGENTS.md`: this Next.js version has breaking changes vs. training data — check `node_modules/next/dist/docs/` before relying on remembered Next.js APIs/conventions.
